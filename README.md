# MorphoGraph

### Brain Tumor MRI Segmentation and Classification Web Application

MorphoGraph is a research-oriented web application designed to support brain MRI image analysis using deep learning and graph-based learning techniques.

The application aims to provide a simple interface for uploading brain MRI images, performing model inference, and visualizing classification and segmentation results.

## Planned Features

- Brain MRI image upload and preview
- Four-class MRI classification
- Brain tumor segmentation visualization
- Prediction confidence scores
- Responsive web interface
- Integration with trained deep learning models

## Technology Stack

**Frontend:** React.js, Vite, Tailwind CSS

**Backend:** Python, FastAPI

**Deep Learning:** PyTorch

**Graph Learning:** PyTorch Geometric

**Version Control:** Git and GitHub
